# 7TV Mod Log Filtering
---
## About
7TV Mod Log Filtering is a chrome extension that serves to improve a feature from the very popular Twitch/Kick extension 7TV. "Mod Logs" is one of many features that 7TV offers to the user and its specific purpose is to provide information regarding chat moderation. This project seeks to enhance the clarity of the feature by enabling the user to filter the logs.

## Installation and Usage
Getting an extension on the chrome store seems like a hassle so I'm not doing that.

To install the extension you will have to 
First: Make sure you have the 7TV extension added and enabled on your browser.
Then:
1. Download and unzip the files / clone the repo.
2. Go to chrome://extensions, just write it in your search bar.
3. Enable "Developer mode" in the top right.
4. Click "Load unpacked" in the top left.
5. Select the folder.
6. Reload or open twitch.tv
7. Enjoy!

The useage of the extension is self-explanatory. If no timeouts or bans have occured since last reloading/opening the site then the feature will not show up.
